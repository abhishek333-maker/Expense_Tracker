# Expense Tracker – CLI Based Application

A command-line Expense Tracker built in Python that helps users record, organize,
and analyze their daily expenses, and track spending against a monthly budget.

> Software Development Internship Project — CodeOrbit Tech (Batch IND1)

## Technologies Used
- **Language:** Python 3
- **Application Type:** Command-Line Interface (CLI)
- **Data Storage:** CSV (Comma-Separated Values) files
- **Development Environment:** Visual Studio Code
- **Version Control:** Git & GitHub
